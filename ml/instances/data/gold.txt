# Tags (see README.md for the full rules):
#   INSTANCE  a thing to create: head noun plus the words that name its kind ("pricing table", "25 minute timer"); no article, count or color
#   REF       something already on the board: @handles, {braced names}, it / them / this / everything, "the hero" (article left out)
#   COUNT     how many: 3, three, trio, "4 of them" -> 4
#   RELATION  a verb that links two things: calls, writes to, publishes to, connected to, connect, uses
#   ACTION    an edit verb: remove, delete, move, rename, change, make, color, disconnect, detach, group, wrap, put, call (naming)
#   ATTR      a property: color, size, layout word, sequence ("increments of 15"), position ("at the top", "before", "between")
#   NAME      a name or value given in the text: "called [postgres]", "call it [Login]", list items after a colon, note text

#   dst   where a relation or edit goes: [postgres](INSTANCE dst:writes to), [@navbar](REF dst:above), [clock](INSTANCE dst:change)
